my work

Things I've built, broken, and learned from.

Some of this solves a real problem for a real robot. Some of it exists because I wanted to know if it could be done. Tap a project to open it up.

The idea. Classical planners like RRT search for a path step by step. I wanted to know if a diffusion model, the same family of model behind image generation, could learn to "denoise" a rough path into a smooth, collision-aware trajectory instead.

The build. A hierarchical diffusion planner trained on BiRRT-sampled paths across SLAM-mapped environments, wired into a TurtleBot's navigation stack via ROS2 and Nav2.

The stack. Python, PyTorch, ROS2, Nav2, SLAM.

What I learned. How much of "good navigation" is actually about the shape of your training distribution, not just the model architecture. This project set the direction for everything I've worked on since.

The problem. A robot cleans the inside of shipping containers with high-pressure water and air. LiDAR returns scatter off airborne mist; ultrasound drowns in blower noise. There's no gap in the spray to sense around: the interference is constant.

The approach. Rather than fight the sensors the environment defeats, I'm building a 3D map of the container from LiDAR and camera in advance, so the robot can localize against known wall geometry instead of trusting live noisy returns. That's mcs_mapping, a ROS2 package with an ICP pipeline running on Jetson.

The stack. Hesai JT128 LiDAR, ICP, visual odometry with ORB feature matching, ROS2, Jetson.

Where it stands. Actively debugging mapping artifacts and exploring mmWave radar as a longer-term answer to the mist problem itself.
