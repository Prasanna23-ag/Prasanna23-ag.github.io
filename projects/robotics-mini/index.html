Robotics Mini Projects

A batch of embedded robot builds — where sensor-based control and wireless motion handling first clicked for me.

The builds. Seven small embedded robots, each built to explore a different sensing or control problem, using IR/LDR sensors, motor drivers, wireless modules, and embedded C:

  • Obstacle Avoider — navigates around obstacles using IR sensing.
  • Tabletop-Edge Detector — stops the robot before it drives off a raised surface.
  • PC-Controlled Robot — driven directly from a PC interface.
  • Light-Sensitivity Robot — reacts to changes in ambient light using LDR sensors.
  • Wireless Robot — untethered control over a wireless link.
  • Pickup-and-Place Robot — picks up and repositions objects.
  • Line Follower — tracks a marked path autonomously.

What it taught me. Every build forced a different combination of sensor input and motor output through embedded C, which is what got me hooked on the sensing-to-actuation loop that's stayed at the center of everything I've built since.
