Voice-Controlled Navigation

Say where to go, and a simulated robot goes there, in whatever accent you've got.

The idea. Most voice-control demos only work with one accent, spoken clearly, one command at a time. I wanted something more forgiving.

The build. A ROS2 package that controls a TurtleBot3 in Gazebo via spoken commands, publishing velocity commands over /cmd_vel. Multi-accent speech recognition covers five English and German locales, with fuzzy matching for robust command interpretation.

The sequencing. A command-queueing system supports multi-step voice sequences, with automatic timed execution and a safety auto-stop.

The stack. ROS2, OpenAI Whisper, Gazebo, Python.
